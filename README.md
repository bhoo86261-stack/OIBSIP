# OIB-SIP Internship Projects

This repository contains my completed projects for the OIB-SIP Data Science Internship.

## Task 1 - Exploratory Data Analysis (EDA) on Retail Sales Data

### Objective
Performed exploratory data analysis on a retail sales dataset to identify sales trends, customer behaviour and business insights.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Work Performed
- Loaded and inspected the dataset
- Checked shape, data types and missing values
- Calculated mean, median, mode and standard deviation
- Performed monthly and quarterly sales trend analysis
- Analysed customer age and gender
- Identified top-selling products
- Analysed revenue by product category
- Created correlation heatmap
- Created additional visualisations
- Added observations after visualisations
- Provided actionable business recommendations

### Outcome
The analysis identified important sales, customer and product trends that can support better business decisions.

## Task 2 - Customer Segmentation Analysis

### Objective
Segmented customers into different groups based on their purchasing behaviour to support targeted marketing strategies.

### Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- K-Means Clustering
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

### Work Performed
- Loaded and inspected the customer dataset
- Handled missing and inconsistent data
- Calculated customer purchasing metrics
- Selected behavioural features for segmentation
- Standardised the selected features
- Used the Elbow Method to determine the number of clusters
- Applied K-Means clustering
- Visualised customer clusters using scatter plots
- Created cluster profiles
- Created a bar chart showing customers per cluster
- Suggested marketing actions for each customer segment

### Outcome
Customers were divided into meaningful groups based on their purchasing behaviour, helping identify different customer types and suitable marketing strategies.

## Task 3 - Data Cleaning

### Objective
Cleaned a messy housing dataset and transformed it into an analysis-ready dataset.

### Tools Used
- Python
- Pandas
- NumPy
- Google Colab / Jupyter Notebook

### Work Performed
- Loaded and inspected the dataset
- Created a data quality report
- Checked missing values
- Checked duplicate rows
- Identified data type issues
- Checked value ranges and anomalies
- Handled missing values using suitable methods
- Removed duplicate records
- Standardised inconsistent values
- Detected numerical outliers using the IQR method
- Corrected column data types
- Created a before-and-after data quality summary
- Saved the cleaned dataset as a new CSV file

### Outcome
The messy dataset was transformed into a clean, consistent and analysis-ready dataset.
